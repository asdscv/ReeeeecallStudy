# 두뇌 트레이닝 — 게임 연출(Game feel) 기준

> 2026-11-12. 대표 요청 «AAA급 서비스 게임 수준으로, 처음부터 싹 확인해서». 근거·문구 게이트는 [`EVIDENCE.md`](EVIDENCE.md)가 우선한다.

## 1. 한 뼈대, 아홉 옷

모든 게임은 같은 배치(헤더 · 점수/연속/기회 · 진행·시간 막대 · 문제 · 판 · 판정)를 쓰고, 게임마다 색만 바뀐다 — 노인 사용자는 새 배치에 대한 부담이 크다.

- 색: `shared/lib/brain-games/theme.ts` `GAME_THEMES` — 허브 카드 그라데이션(흰 글자 4.5:1 이상), 게임 화면은 라이트 모드에서도 어두운 캔버스, 강조색(캔버스 대비 7:1 이상). 정답 초록·오답 빨강은 어떤 게임의 강조색으로도 쓰지 않고, 항상 ✓·✕ 아이콘을 같이 쓴다.
- 색깔 단어 잉크: `INK_COLORS`(흰 카드 위 4.5:1, 주황만 3.6:1 — 40px 이상 큰 글자 기준 3:1 충족).

## 2. 흐름

소개(게임 아이콘·이름·한 줄 목표 · **실제 엔진이 스스로 푸는 데모** · 레벨/플레이/최고점 · 시작) → 3·2·1·시작 → 라운드 → «라운드 끝» 도장 1.3초 → 결과(별 · 점수 카운트업 · 내 최고 대비 · 레벨 변화 · 최근 추세선 · 한 판 더/다른 게임).
오늘의 훈련: 구성 화면(4게임·분·주간 링) → 게임마다 소개(단계 아이콘) → 라운드 → 다음 게임 소개 → 완료(폭죽·주간 링·과정 막대·게임별 변화).

- 데모는 `buildDemo()`가 엔진의 `solution()`으로 쉬운 판을 직접 풀어 만든 프레임이다. 그래서 설명과 실제 게임이 어긋날 수 없고, 같은 `solution()`으로 시험이 모든 게임·레벨·화면을 자동으로 끝까지 풀어 본다.
- 폭죽은 개인 최고(첫 판 제외)와 오늘의 훈련 완료에만 쓴다. 평범한 끝·최고 미달·낮은 정답률엔 축하하지 않는다. 내 최고 미달은 빨간 글씨 없이 «최고 기록 N»만.
- 연속 정답 배지(3·6·10)와 별(정답률 75%/90%)은 **라운드 안의 피드백**이다. EVIDENCE.md가 막는 «연속 일수 주 지표·뇌 나이·두뇌 점수·백분위·주 3회 초과 보상»에 해당하지 않는다.

## 3. 효과 이벤트

`shared/hooks/useBrainFx.ts` — 라운드 상태(판·판정)에서 이벤트를 뽑는다(탭 처리기가 아니라서 엔진이 무시한 탭은 소리도 안 난다): reveal · flash(시퀀스 칸마다 고유음) · stimulus · hit(누를수록 음이 올라감) · miss · flip · select · correct · wrong · lifeLost · levelUp(정수 레벨만) · void · roundEnd · newBest.

- 웹 소리(`web/src/components/brain/sfx.ts`, Web Audio 합성): 사인·삼각파만, 1.3kHz 이하 C장조 5음계(노인 고음역 청력 저하), 오답은 «툭» 낮은 음, 마지막 탭은 판정음만. 설정·일시정지 화면에서 끄기.
- 앱 진동(`mobile/src/components/brain/fx-haptics.ts`): 앱 전체 진동 설정을 따른다. 빠른 눈 노출·시퀀스 재생 중엔 진동하지 않는다(자극을 흐리거나 알려 준다). 최소 간격 80ms.
- 앱엔 오디오 모듈이 없다(추가하면 네이티브 빌드·스토어 심사 필요) — 앱은 진동과 시각만으로 모든 판정을 전한다.

## 4. 모션

팝 240ms(살짝 넘침) · 흔들림 320ms ±7px(고른 칸만, 화면 전체는 흔들지 않음) · 카드 뒤집기 200ms · 등장 260ms · 점수 +N 900ms 떠오름. 시간 막대는 남은 1/3부터 호박색, 1/6부터 빨강(째깍 소리는 넣지 않음 — 노인에게 시간 압박을 키운다). 줄인 동작 설정이면 이동·확대·폭죽·카운트업을 끄고 색·아이콘·소리·진동은 그대로.

## 5. 이번에 고친 엔진 결함(독립 감사 24건 전부 실재 확인)

- 일시정지가 기억 단계를 처음부터 다시 보여 줌 → 남은 시간 유지(무제한 외우기 차단)
- 시간 여유 모드에서 기억 게임을 기다리기만 하면 같은 길이가 영원히 반복 → 빈 답은 기회 차감, 기억 게임 라운드 14문제 상한
- 퍼즐은 더 어려워지지 않는데 레벨만 오름(숫자 순서·다른 하나·같은 그림·색깔 단어·순간 기억) → 시간 단축 레버 + 게임별 상한(`maxLevel`, 순간 기억은 화면 크기별)
- 빠른 눈: 33ms 하한에서 11·12단계가 같은 화면인데 12/12 표시 → 레벨 대신 **실제 노출 ms** 표시, 기기 하한 단계에서 멈춤
- 빠른 눈 무효 시행이 끝없이 이어짐 → 연속 5번이면 실제 노출을 그대로 인정, 8번이면 라운드 종료
- 오늘의 훈련 «누적 분»이 일시정지·화면 대기까지 셈 → 실제 플레이 시간만(계획의 1.5배 상한)
- 손상된 저장 레벨(1e308)로 빠른 계산이 멈춤 → 읽을 때 범위 제한, 보기 생성 루프 상한
- 'l'/'I' 구분 불가 짝 제거, 같은 그림 미리보기 급락(레벨 18) 완화, 웹 빠른 눈 바깥 고리 배치를 앱과 같은 화면 기준으로

시험: `web/src/lib/__tests__/brain-games.test.ts`(solution()으로 9게임×15레벨×3화면 자동 풀이, 데모, 기록 크기), `brain-round-hook.test.ts`(가짜 시계로 일시정지·라운드 종료·상한·실제 시간).
