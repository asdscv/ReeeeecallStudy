REKLUE / BRAND ASSETS · 2026

The stacked cards represent recall. A custom R is drawn into the front card.
Primary: digital/large sizes. Flat: compact screens/embroidery. Black/white: one-color print; the R is a true transparent knockout. Outline: supporting use only. Micro: 16–48 px.
Use horizontal lockups in headers; stacked lockups for square covers. Korean lockups are included. SVG files contain paths, so no font installation is needed. PNG files are transparent unless named social.
Keep clear space of at least 1/4 of the front card width. Do not stretch, add shadows, or place the blue symbol on busy backgrounds. Small UI symbols should use micro instead of outline.
